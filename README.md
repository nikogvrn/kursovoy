### Вариант 9. Мониторинг реактора: расход охлаждающей жидкости
Параметр Расход охлаждающей жидкости (X)
Единица л/мин
Диапазон X 5 … 80
Нормальное состояние штатный режим: 30–55 л/мин; значения вне диапазона рассматриваются как отклонение технологического Количество измерений N = 50
1. Преобразование показания
$$
Q(X)=
\begin{cases}
3\ln(X-30+2)+10, & X<30,\\
2(X-42.5)+48, & 30\le X\le55,\\
5\sqrt{X-55+1}+58, & X>55.
\end{cases}
$$
2. Оперативный контроль
Проверка устойчивости. Базовое значение Q₀ = 48.00, допустимое отклонение ±10%. Состояние нарушения
фиксировать только при двух последовательных выходах за диапазон. Названия состояний студент
определяет самостоятельно.
3. Статистический анализ
Для Q[21..40] вычислить: число локальных максимумов и значение максимального пика.
