Параметр Расход охлаждающей жидкости (X)
Единица л/мин
Диапазон X 5 … 80
Нормальное состояние штатный режим: 30–55 л/мин; значения вне диапазона рассматриваются как отклонение технологического Количество измерений N = 50
1. Преобразование показания
```math
Q(X)=
\begin{cases}
3\ln(X-30+2)+10, & X<30,\\
2(X-42.5)+48, & 30\le X\le55,\\
5\sqrt(X-55+1)+58, & X>55.
\end{cases}
```

Проверка устойчивости. Базовое значение Q₀ = 48.00, допустимое отклонение ±10%. Состояние нарушения

## 2. Реализация программы

Исходный файл программы — Kursovoy.c.
Функция calculate_q() вычисляет значение Q(X). В main() проверяется корректность ввода, диапазон показаний датчика и область определения логарифма. Если проверка не пройдена, программа выводит сообщение об ошибке. При корректном вводе программа выводит X и рассчитанное Q(X).

Ручная проверка расчёта

При X = 29:

Q = 3·ln(29−30+2)+10 = 3·ln(1)+10 = 10.00.

При X = 48:

Q = 2·(48−42.5)+48 = 2·5.5+48 = 59.00.
