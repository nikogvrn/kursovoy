## Условие задачи

### Вариант 9. Мониторинг реактора: расход охлаждающей жидкости
Параметр Расход охлаждающей жидкости (X)
Единица л/мин
Диапазон X 5 … 80
Нормальное состояние штатный режим: 30–55 л/мин; значения вне диапазона рассматриваются как отклонение технологического Количество измерений N = 50
1. Преобразование показания
```math
Q(X)=
\begin{cases}
3\ln(X-30+2)+10, & X<30,\\
2(X-42.5)+48, & 30\le X\le55,\\
5\sqrt(X-55+1)+58, & X>55.
\end{cases}
```
2. Оперативный контроль
Проверка устойчивости. Базовое значение Q₀ = 48.00, допустимое отклонение ±10%. Состояние нарушения
фиксировать только при двух последовательных выходах за диапазон. Н
3. Статистический анализ
Для Q[21..40] вычислить: число локальных максимумов и значение максимального пика.

## 2. Реализация программы

Программа написана на языке C. Функция `calculate_q` вычисляет `Q(X)` по соответствующей ветви формулы.

Функция main задаёт параметры контроля, открывает входной и выходной файлы, считывает показания из input.txt, проверяет допустимость X, вычисляет Q и присваивает состоянию значение НОРМА или ПРЕДУПРЕЖДЕНИЕ. Результаты выводятся на экран и записываются в results.txt.
Входной файл содержит 50 числовых показаний — по одному значению в строке. Параметры контроля в текущей версии заданы в коде: `Q₀ = 48`, допустимое отклонение — `10%`.

Ручная проверка расчёта

При X = 29:

Q = 3·ln(29−30+2)+10 = 3·ln(1)+10 = 10.00.

При X = 48:

Q = 2·(48−42.5)+48 = 2·5.5+48 = 59.00.
