## Условие задачи

Программа реализует функцию преобразования показания расхода охлаждающей жидкости (X) в расчётное значение (Q(X)).
## 1. Алгоритм и блок-схема

Алгоритм
1. Получить значение (X).

2. Проверить условие (X<30).

3. Если условие выполняется, вычислить первую ветвь.

4. Иначе, если (X<=55), вычислить вторую ветвь.

5. В противном случае вычислить третью ветвь.

6. Вернуть и вывести результат (Q(X)).
