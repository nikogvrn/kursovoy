## Условие задачи

### Вариант 9. Мониторинг реактора: расход охлаждающей жидкости
1. Преобразование показания

```math
Q(X)=
\begin{cases}
3\ln(X-30+2)+10, & X<30,\\
2(X-42.5)+48, & 30\le X\le55,\\
5\sqrt(X-55+1)+58, & X>55.
\end{cases}
```

В первой ветви аргумент логарифма равен X−28. Поэтому эта ветвь определена только при X > 28. Для значений 5 ≤ X ≤ 28 формула из задания не определена, и программа сообщает о таком показании и пропускает его.

#### 2. Оперативный контроль

Базовое значение — Q₀ = 48.00, допустимое отклонение — ±10%. Программа запрашивает эти два параметра при запуске и вычисляет границы контроля. При значениях по умолчанию границы Q составляют [43.20; 52.80].

В текущей версии каждое показание получает состояние «НОРМА», если Q попадает в границы, или «ПРЕДУПРЕЖДЕНИЕ», если выходит за них. Правило задания о фиксации нарушения только после двух последовательных выходов будет добавлено на следующем этапе.

#### 3. Статистический анализ

Для значений Q[21..40] по заданию нужно определить количество локальных максимумов и значение максимального пика. Этот этап пока не реализован.

#### 4. Дополнительное задание

Дополнительное задание будет описано после его согласования с преподавателем.

#### 5. Контрольный пример

При X = 48.00 л/мин ожидается Q = 59.00.

## 1. Алгоритм и блок-схема
Начало
1. Начать работу и ввести базовое значение Q₀ и допустимое отклонение.
2. Вычислить нижнюю и верхнюю границы контроля.
3. Открыть `input.txt` для чтения и `results.txt` для записи.
4. Последовательно читать показания X из входного файла.
5. Проверить, что X входит в диапазон 5–80 и что формула определена для этого значения.
6. Вычислить Q(X).
7. Сравнить Q с границами контроля и определить состояние.
8. Показать результат на экране и записать его в `results.txt`.
9. Продолжать обработку до конца файла; сообщить о пустом файле или некорректной записи.
10. Закрыть файлы и завершить работу.

## 2. Реализация программы

Программа написана на языке C. Функция `calculate_q` вычисляет Q(X) по одной из трёх ветвей формулы.

Функция `main` запрашивает Q₀ и допустимое отклонение, вычисляет границы контроля, открывает входной и выходной файлы, затем последовательно обрабатывает показания из `input.txt`. Для каждого допустимого X программа вычисляет Q, определяет состояние и выводит результат на экран и в `results.txt`. Также программа сообщает об ошибках открытия файлов, пустом файле, некорректной записи, выходе X за диапазон 5–80 и значениях, для которых формула не определена.

Ручная проверка расчёта

При X = 29:

Q = 3·ln(29−30+2)+10 = 3·ln(1)+10 = 10.00.

При X = 48:

Q = 2·(48−42.5)+48 = 2·5.5+48 = 59.00.
